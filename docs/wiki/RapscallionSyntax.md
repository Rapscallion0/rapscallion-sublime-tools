# RapscallionSyntax

Domain-specific `.sublime-syntax` definitions and color schemes for log analysis and structured data files.

## Included Definitions
- **`SL4` Log Syntax**: High-contrast highlighting for POS/application `.sl4` logs (timestamps, severity levels, transaction markers, payloads).
- **`LOC` Syntax** (`LOC.sublime-syntax`): Specialized syntax scoping for structured `.loc` files.
- **Auto-Assignment**: Automatically activates based on file extensions without manual configuration.
