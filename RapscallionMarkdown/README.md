# RapscallionMarkdown

Zero-dependency live Markdown viewer and editor for Sublime Text 4.

## Features
- **Side-Panel Preview (`Ctrl+Alt+M, P`)**: Theme-aware `minihtml` HTML sheet with clickable task checkboxes (`- [ ]` / `- [x]`), heading jump links, and relative file navigation.
- **Live Browser Preview (`Ctrl+Alt+M, B`)**: Built-in localhost HTTP + Server-Sent Events (SSE) server that updates your browser in real time as you type, with auto/light/dark theme switching, sync-scroll, copy-code buttons, and two-way checkbox toggling.
- **Stop Browser Server (`Ctrl+Alt+M, X`)**: Cleanly shuts down the background preview server.
